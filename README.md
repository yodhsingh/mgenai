# SECTION 1 - f-DIVERGENCE AND VARIATIONAL FORM

## 1.1 Probability Distributions and Divergence

**Definition:** A probability distribution tells how likely each possible data point is. In Generative AI:

- `P_data(x)` or `P(x)` = real/data distribution
- `P_g(x)` or `Q(x)` = generator/model distribution

A divergence measures how different two probability distributions are.

**Why needed:** Generator good tab hovega jadon `P_g(x) ≈ P_data(x)`. Is comparison layi mathematical number chahida.

**Punjabi intuition:** Real data distribution teacher vargi hai, generator distribution student vargi. Divergence check karda hai student teacher ton kina door hai.

**Common point:** Divergence is usually not symmetric:

```math
D(P||Q) \neq D(Q||P)
```

This is unlike Euclidean distance.

## 1.2 f-Divergence

**Definition:** f-divergence is a family of divergences generated by choosing a convex function `f` with `f(1)=0`.

```math
D_f(P||Q)=E_Q\left[f\left(\frac{P(x)}{Q(x)}\right)\right]
```

Equivalent integral form:

```math
D_f(P||Q)=\int Q(x) f\left(\frac{P(x)}{Q(x)}\right) dx
```

**Symbols:**

- `P` = target/real distribution
- `Q` = model/reference distribution
- `P(x)/Q(x)` = density ratio
- `f` = convex function
- `E_Q` = expectation under distribution `Q`
- `f(1)=0` = if `P=Q`, divergence should be zero

**Why needed:** Many divergences such as KL, Reverse KL, JS, Pearson chi-square, and Total Variation can be studied using one framework.

**Punjabi intuition:** f-divergence ek family hai. Function `f` badlo, divergence type badal jandi.

## 1.3 Examples of f-Divergences

| Divergence | f(t) | Formula / Note |
|---|---:|---|
| KL `D_KL(P||Q)` | `t log t` | `E_P[log(P/Q)]` |
| Reverse KL `D_KL(Q||P)` | `-log t` | mode-seeking behavior in many contexts |
| Jensen-Shannon | mixture-based | GAN theory connection |
| Pearson chi-square | `(t-1)^2` | density ratio squared error style |
| Total Variation | `1/2 |t-1|` | maximum probability gap |

**Additional Concept:** Hellinger and Neyman chi-square are also often treated under f-divergence families, but this must be checked against the missing uploaded notes.

**Which measure is NOT an f-divergence?**

Important PYQ trap from the conversation:

```text
Wasserstein distance is NOT an f-divergence.
```

## 1.4 Fenchel Conjugate

**Definition:**

```math
f^*(u)=\sup_t \{ut-f(t)\}
```

**Symbols:**

- `f*` = Fenchel conjugate of `f`
- `u` = dual variable / critic output value
- `sup` = supremum, maximum-like upper value
- `t` = density ratio variable

**Why needed:** It converts the original divergence into a variational optimization problem. This is the bridge toward GAN-like objectives.

**Punjabi intuition:** Direct density ratio `P/Q` mushkil hai. Fenchel conjugate naal asin critic/network through divergence estimate kar sakde haan.

## 1.5 Variational Representation

```math
D_f(P||Q)=\sup_T \left\{E_P[T]-E_Q[f^*(T)]\right\}
```

Optimal critic:

```math
T^*(x)=f'\left(\frac{P(x)}{Q(x)}\right)
```

**Symbols:**

- `T` = critic/test function/neural network
- `T*(x)` = optimal critic
- `f'` = derivative of `f`
- `E_P[T]` = average critic score on real distribution
- `E_Q[f*(T)]` = penalty under model distribution

**Reasoning:** Fenchel inequality says:

```math
f(t) \ge ut - f^*(u)
```

At optimum, `u=f'(t)`. Put `t=P(x)/Q(x)`, and the optimal critic becomes `T*(x)=f'(P(x)/Q(x))`.

**Numerical Example 1: Density ratio**

If `P(x)=0.6` and `Q(x)=0.3`,

```math
\frac{P(x)}{Q(x)}=\frac{0.6}{0.3}=2
```

Meaning: this point is twice as common in real data as in model data.

**Numerical Example 2: KL contribution**

For KL, `f(t)=t log t`. If `t=2`,

```math
f(2)=2\log 2 \approx 1.386
```

If `Q(x)=0.3`, contribution is:

```math
0.3(1.386)=0.416
```

**PYQ/PYQ-style Questions**

1. Define f-divergence and explain the role of convex `f`.
2. Why must `f(1)=0`?
3. Write the variational representation of f-divergence.
4. Which is not an f-divergence: KL, JS, Total Variation, Wasserstein?

**Common Traps**

- Do not treat divergence as always symmetric.
- Do not confuse f-divergence critic with WGAN critic.
- Do not say Wasserstein is an f-divergence.
- Density ratio is `P/Q`, not always `Q/P`; check formula order.

**Memory Trick:** `f-divergence = function f applied to density ratio P/Q`.

# SECTION 2 - GAN

## 2.1 Generator and Discriminator

**Definition:** GAN has two networks:

- Generator `G(z)` creates fake samples from noise `z`.
- Discriminator `D(x)` predicts whether input is real or fake.

```text
z → Generator → Fake sample
Real + Fake → Discriminator → real/fake probability
```

**Why needed:** GAN learns generation without explicitly writing likelihood.

**Punjabi intuition:** Generator fake notes banaunda, Discriminator police officer hai. Dono improve karde ne: fake better, checking stricter.

## 2.2 Minimax Objective

```math
\min_G \max_D V(D,G)
=E_{x\sim P_{data}}[\log D(x)]
+E_{z\sim p(z)}[\log(1-D(G(z)))]
```

Using `x~P_g` for generated samples:

```math
E_{x\sim P_g}[\log(1-D(x))]
```

**Symbols:**

- `G` = generator
- `D` = discriminator
- `z` = latent noise vector
- `P_data` = real distribution
- `P_g` = generator distribution
- `D(x)` = probability that `x` is real

## 2.3 Optimal Discriminator

```math
D^*(x)=\frac{P_{data}(x)}{P_{data}(x)+P_g(x)}
```

Density ratio:

```math
\frac{P_{data}(x)}{P_g(x)}=\frac{D^*(x)}{1-D^*(x)}
```

**Reasoning:** For fixed `G`, maximize:

```math
P_{data}(x)\log D(x)+P_g(x)\log(1-D(x))
```

Taking derivative and setting to zero gives the optimal discriminator formula.

**Numerical Example 1**

If `P_data=0.6`, `P_g=0.2`,

```math
D^*=\frac{0.6}{0.6+0.2}=0.75
```

**Numerical Example 2**

If `D*=0.75`,

```math
\frac{P_{data}}{P_g}=\frac{0.75}{1-0.75}=3
```

Meaning: real density is 3 times generated density at that point.

## 2.4 Saturating vs Non-Saturating Loss

Original/saturating generator loss:

```math
\min_G E_z[\log(1-D(G(z)))]
```

Non-saturating generator loss:

```math
\min_G -E_z[\log D(G(z))]
```

**Why needed:** Original loss can have vanishing gradients when discriminator becomes too strong. Non-saturating loss gives stronger learning signal.

## 2.5 Mode Collapse

**Definition:** Generator produces limited varieties of samples, ignoring many modes of data distribution.

**Punjabi intuition:** Agar exam vich 10 chapters ne but student sirf 2 chapters hi revise kare, oh mode collapse varga hai.

## 2.6 Conditional GAN

**Additional Concept:** Conditional GAN uses condition `y` such as class label:

```math
\min_G\max_D E_{x\sim P_{data}}[\log D(x|y)]
+E_{z\sim p(z)}[\log(1-D(G(z|y)|y))]
```

Check missing source notes for exact notation.

## 2.7 DCGAN

**Additional Concept:** DCGAN usually means GAN using convolutional neural networks for images. Common rules include strided convolutions, batch normalization, and no fully connected layers in deeper image parts, but exact source coverage is unavailable.

**PYQ/PYQ-style Questions**

1. Derive the optimal discriminator for GAN.
2. Explain saturating and non-saturating generator loss.
3. What is mode collapse?
4. If `D*(x)=0.8`, calculate `P_data/P_g`.

**Common Traps**

- Discriminator outputs probability; WGAN critic outputs unrestricted score.
- `D*(x)` denominator is `P_data + P_g`.
- Non-saturating loss changes generator training, not discriminator objective.
- Mode collapse is not just poor image quality; it is lack of diversity.

**Memory Trick:** `GAN = G tries to fool, D tries to detect`.

# SECTION 3 - WGAN

## 3.1 Problem with Standard GAN

Standard GAN can suffer from:

- vanishing gradients
- unstable training
- mode collapse
- weak signal when real and generated distributions do not overlap

**Why WGAN needed:** Wasserstein distance gives smoother, more meaningful training signal.

## 3.2 Wasserstein / Earth Mover Distance

**Definition:** Wasserstein distance measures minimum cost to transport mass from one distribution to another.

**Punjabi intuition:** Mitti di pile A nu pile B shape vich shift karna. Jinna zyada mass door leke jana, cost ohni zyada.

**Important:** Wasserstein distance is **not** an f-divergence.

## 3.3 Kantorovich-Rubinstein Duality

```math
W_1(P,Q)=\sup_{\|D\|_L\le 1}\left(E_P[D]-E_Q[D]\right)
```

**Symbols:**

- `W1` = Wasserstein-1 distance
- `D` = critic function
- `||D||_L ≤ 1` = 1-Lipschitz constraint
- `E_P[D]` = critic score on real samples
- `E_Q[D]` = critic score on fake samples

## 3.4 Critic vs Discriminator

| GAN Discriminator | WGAN Critic |
|---|---|
| outputs probability | outputs real-valued score |
| uses log loss | uses score difference |
| bounded 0 to 1 | not necessarily bounded as probability |
| classifies real/fake | estimates distribution distance |

## 3.5 1-Lipschitz Constraint

**Definition:** Critic must not change faster than allowed:

```math
|D(x_1)-D(x_2)| \le |x_1-x_2|
```

**Why needed:** Required by Kantorovich-Rubinstein dual form.

## 3.6 Weight Clipping and Gradient Penalty

**Weight clipping:** Clip critic weights into a small range, e.g. `[-c,c]`. It enforces Lipschitz roughly but can hurt capacity.

**Gradient penalty (WGAN-GP):**

```math
GP=\lambda(\|\nabla D(\hat{x})\|_2-1)^2
```

Usually added to critic loss.

**Symbols:**

- `λ` = penalty strength
- `∇D(x_hat)` = gradient of critic with respect to interpolated sample
- `||.||2` = Euclidean norm
- `x_hat` = point between real and fake samples

**Numerical Example 1: Transport cost**

Move mass `0.4` by distance `3`:

```math
cost=0.4\times 3=1.2
```

**Numerical Example 2: Gradient penalty**

If `λ=10` and `||∇D(x_hat)||2=1.3`,

```math
GP=10(1.3-1)^2=10(0.09)=0.9
```

## 3.7 Multiple Critic Steps

WGAN often trains critic multiple times per generator update so the distance estimate is useful before updating generator.

**PYQ/PYQ-style Questions**

1. Why does WGAN replace discriminator with critic?
2. State Kantorovich-Rubinstein duality used in WGAN.
3. Why is 1-Lipschitz constraint required?
4. Calculate gradient penalty for `λ=5`, gradient norm `0.6`.

**Common Traps**

- Critic is not a probability classifier.
- Wasserstein distance is not an f-divergence.
- Gradient penalty targets gradient norm near 1, not 0.
- Weight clipping and gradient penalty are different Lipschitz enforcement methods.

**Memory Trick:** `WGAN = Wasserstein + critic + 1-Lipschitz`.

# SECTION 4 - VAE

## 4.1 Autoencoder vs VAE

**Autoencoder:** learns compressed representation and reconstruction:

```text
x → Encoder → z → Decoder → x_hat
```

**VAE:** learns a probability distribution in latent space:

```text
x → Encoder → μ, σ → sample z → Decoder → x_hat
```

**Why needed:** VAE makes latent space smooth and sampleable, so we can generate new data by sampling `z`.

**Punjabi intuition:** Autoencoder direct code store karda. VAE kehnda: code exact point nahi, ek Gaussian area hai jithon sample kar sakde haan.

## 4.2 Encoder, Decoder, Prior, Posterior

```math
q_\phi(z|x)=N(\mu(x),\sigma^2(x))
```

```math
p(z)=N(0,I)
```

**Symbols:**

- `q_phi(z|x)` = approximate posterior from encoder
- `p(z)` = prior distribution
- `μ` = mean predicted by encoder
- `σ` = standard deviation predicted by encoder
- `z` = latent variable
- `x_hat` = reconstructed output

## 4.3 Reparameterization Trick

```math
z=\mu+\sigma\epsilon,\quad \epsilon\sim N(0,I)
```

**Why needed:** Direct sampling blocks gradient flow. Reparameterization moves randomness into `epsilon`, making training differentiable.

**Numerical Example**

If `μ=2`, `σ=0.5`, `ε=1`:

```math
z=2+0.5(1)=2.5
```

## 4.4 ELBO and VAE Loss

Loss form:

```math
L_{VAE}=L_{reconstruction}+D_{KL}(q_\phi(z|x)||p(z))
```

ELBO maximization equivalent:

```math
ELBO=E_{q(z|x)}[\log p_\theta(x|z)]-D_{KL}(q_\phi(z|x)||p(z))
```

**Reasoning:** VAE balances:

- reconstruction: output should match input
- KL regularization: latent distribution should stay close to prior

## 4.5 Gaussian KL Formula

For diagonal Gaussian against standard normal:

```math
D_{KL}=
-\frac12\sum_i(1+\log\sigma_i^2-\mu_i^2-\sigma_i^2)
```

Equivalent:

```math
D_{KL}=
\frac12\sum_i(\mu_i^2+\sigma_i^2-1-\log\sigma_i^2)
```

**Numerical Example 1**

If `μ=0`, `σ²=1`:

```math
KL=\frac12(0+1-1-\log 1)=0
```

**Numerical Example 2**

If `μ=1`, `σ²=1`:

```math
KL=\frac12(1+1-1-\log1)=0.5
```

## 4.6 VAE Generation

```text
z ~ N(0,I) → Decoder → new sample
```

**PYQ/PYQ-style Questions**

1. Why does VAE need the reparameterization trick?
2. Write VAE loss and explain both terms.
3. Calculate `z` if `μ=0.3`, `σ=2`, `ε=-1`.
4. When is Gaussian KL zero?

**Common Traps**

- Encoder outputs `μ,σ`, not just one fixed `z`.
- `σ` and `σ²` are different.
- KL term regularizes latent space; reconstruction term preserves input.
- VAE images may be smoother/blurry compared with GAN.

**Memory Trick:** `VAE = reconstruct well + keep z close to N(0,I)`.

# SECTION 5 - beta-VAE

## 5.1 Definition

beta-VAE modifies VAE loss:

```math
L_\beta=L_{reconstruction}+\beta KL
```

**Why needed:** To control strength of latent regularization and encourage disentanglement.

**Punjabi intuition:** `β` KL penalty da volume knob hai. Volume vadhao, latent space zyada disciplined; par reconstruction weak ho sakdi.

## 5.2 Cases

| β value | Meaning |
|---:|---|
| `β=0` | KL disappears; behaves like reconstruction-only autoencoder |
| `β=1` | standard VAE |
| `β>1` | stronger KL regularization; more disentanglement pressure |
| very large `β` | latent too restricted; reconstruction quality can suffer |

**Important distinction:**

```text
beta-VAE β = KL regularization strength
diffusion β_t = noise variance schedule at timestep t
```

They are not the same.

## 5.3 Numerical Examples

If `L_rec=10`, `KL=2`:

- `β=1`: `L=10+1(2)=12`
- `β=4`: `L=10+4(2)=18`
- `β=0`: `L=10`

If `L_rec=6`, `KL=3`, `β=2`:

```math
L=6+2(3)=12
```

## 5.4 Disentanglement

**Definition:** Latent dimensions represent separate meaningful factors.

Example:

- `z1` = smile
- `z2` = face angle
- `z3` = hair
- `z4` = lighting

**Additional Concept:** Disentanglement is encouraged, not guaranteed.

**PYQ/PYQ-style Questions**

1. What happens when `β=0`?
2. Why can very large `β` hurt reconstruction?
3. Distinguish beta-VAE `β` from DDPM `β_t`.
4. Calculate loss for `L_rec=8`, `KL=1.5`, `β=3`.

**Common Traps**

- beta-VAE beta is not diffusion beta.
- Larger beta is not always better.
- `β=1` means standard VAE.
- `β=0` removes KL regularization.

**Memory Trick:** `β up → KL pressure up → disentanglement up, reconstruction may go down`.

# SECTION 6 - VQ-VAE

## 6.1 Continuous vs Discrete Latent Space

**VAE:** continuous latent:

```math
z \in R^d
```

**VQ-VAE:** discrete codebook latent.

```text
x → Encoder → z_e → nearest codebook vector → z_q → Decoder → x_hat
```

**Why needed:** Discrete latent codes can represent token-like compressed structure, useful for images/audio and later generative priors.

**Punjabi intuition:** VAE free continuous location choose karda. VQ-VAE dictionary/codebook vichon nearest word choose karda.

## 6.2 Codebook and Quantization

Codebook:

```math
E=\{e_1,e_2,\ldots,e_K\}
```

Quantization:

```math
z_q=e_k,\quad k=\arg\min_j ||z_e-e_j||_2
```

**Symbols:**

- `z_e` = encoder output
- `e_k` = selected codebook vector
- `z_q` = quantized vector
- `K` = number of codebook entries

## 6.3 Numerical Example

Codebook:

```text
e1=[1,0], e2=[0,1], e3=[2,2]
```

Encoder output:

```text
z_e=[1.1,0.2]
```

Distances:

```math
d(z_e,e_1)=\sqrt{0.1^2+0.2^2}=0.224
```

```math
d(z_e,e_2)=\sqrt{1.1^2+(-0.8)^2}=1.36
```

```math
d(z_e,e_3)=\sqrt{(-0.9)^2+(-1.8)^2}=2.01
```

Nearest is `e1`, so:

```math
z_q=e_1=[1,0]
```

## 6.4 Losses

**Additional Concept:** Common VQ-VAE loss:

```math
L= L_{rec}+||sg[z_e]-e||_2^2+\beta||z_e-sg[e]||_2^2
```

where `sg` means stop-gradient. This exact formula must be confirmed against missing notes.

**Straight-through estimator:** During backpropagation, gradients are copied through quantization approximately because nearest-neighbour selection is not differentiable.

**PYQ/PYQ-style Questions**

1. What is the difference between VAE and VQ-VAE latent space?
2. How is nearest codebook vector selected?
3. Given simple codebook vectors, find `z_q`.
4. Why is straight-through estimator used?

**Common Traps**

- `z_e` is continuous; `z_q` is quantized.
- Codebook vectors are learned, not manually fixed in real training.
- Nearest vector chosen by distance, not probability.
- Straight-through estimator is for gradient flow.

**Memory Trick:** `VQ-VAE = VAE with vector quantized codebook`.

# SECTION 7 - DIFFUSION FOUNDATION

## 7.1 Core Idea from Zero

Diffusion models learn generation by two processes:

```text
Clean image → gradually add noise → pure noise
Pure noise → gradually remove noise → generated image
```

**Forward process:** fixed mathematical noising process.

**Reverse process:** learned denoising process.

**Punjabi intuition:** Photo te thoda-thoda noise paake usnu TV static bana do. Fir model nu sikhao static ton photo wapas kiven banani.

## 7.2 Important Terms

| Term | Meaning |
|---|---|
| `x0` | original clean data |
| `xt` | noisy sample at timestep `t` |
| `T` | final timestep |
| `ε` | Gaussian noise, usually `N(0,I)` |
| `β_t` | noise variance schedule |
| `α_t` | `1-β_t` |
| `α_bar_t` | cumulative product of alphas |
| Markov chain | current state depends only on previous state |

## 7.3 Why Gaussian Noise?

Gaussian noise is mathematically convenient and allows closed-form sampling for `q(x_t|x_0)`.

**PYQ/PYQ-style Questions**

1. Explain forward and reverse process in diffusion.
2. What is timestep `t`?
3. Why does model need timestep conditioning?
4. What does `x_T ≈ N(0,I)` mean?

**Common Traps**

- Forward process is not learned; reverse process is learned.
- Diffusion does not generate in one step like GAN.
- `β_t` controls noise amount, not KL weight.
- `x_t` is noisy data, not pure noise at every timestep.

**Memory Trick:** `Diffusion = add noise fixed, remove noise learned`.

# SECTION 8 - DDPM FORWARD PROCESS

## 8.1 One-Step Forward Distribution

```math
q(x_t|x_{t-1})
=N(\sqrt{1-\beta_t}x_{t-1},\beta_t I)
```

Sampling equation:

```math
x_t=\sqrt{1-\beta_t}x_{t-1}+\sqrt{\beta_t}\epsilon
```

Since:

```math
\alpha_t=1-\beta_t
```

we can write:

```math
x_t=\sqrt{\alpha_t}x_{t-1}+\sqrt{1-\alpha_t}\epsilon
```

**Symbols:**

- `q(x_t|x_{t-1})` = forward noising distribution
- `β_t` = noise variance at timestep `t`
- `I` = identity covariance matrix
- `ε~N(0,I)` = standard Gaussian noise
- `sqrt(1-β_t)` = old signal scaling
- `sqrt(β_t)` = new noise scaling

## 8.2 Direct Sampling from x0

Define:

```math
\bar{\alpha}_t=\prod_{s=1}^{t}\alpha_s
```

Then:

```math
q(x_t|x_0)=N(\sqrt{\bar{\alpha}_t}x_0,(1-\bar{\alpha}_t)I)
```

Direct sampling:

```math
x_t=\sqrt{\bar{\alpha}_t}x_0+\sqrt{1-\bar{\alpha}_t}\epsilon
```

## 8.3 Step-by-Step Derivation Intuition

For one step:

```math
x_1=\sqrt{\alpha_1}x_0+\sqrt{1-\alpha_1}\epsilon_1
```

For two steps:

```math
x_2=\sqrt{\alpha_2}x_1+\sqrt{1-\alpha_2}\epsilon_2
```

Substitute `x1`:

```math
x_2=\sqrt{\alpha_2\alpha_1}x_0 + combined Gaussian noise
```

Because sum of Gaussians is Gaussian, the combined noise variance becomes:

```math
1-\alpha_1\alpha_2
```

So for timestep `t`:

```math
\bar{\alpha}_t=\alpha_1\alpha_2...\alpha_t
```

and:

```math
x_t=\sqrt{\bar{\alpha}_t}x_0+\sqrt{1-\bar{\alpha}_t}\epsilon
```

## 8.4 Numerical Examples

**Example 1: One-step forward**

If `x_(t-1)=0.8`, `β_t=0.25`, `ε=1`:

```math
x_t=\sqrt{0.75}(0.8)+\sqrt{0.25}(1)
```

```math
x_t=0.866(0.8)+0.5=1.193
```

**Example 2: Direct sampling**

If `α_bar_t=0.64`, `x0=0.5`, `ε=1`:

```math
x_t=\sqrt{0.64}(0.5)+\sqrt{0.36}(1)
```

```math
x_t=0.8(0.5)+0.6=1.0
```

**Example 3: α_bar_t = 1**

```math
x_t=\sqrt{1}x_0+\sqrt{0}\epsilon=x_0
```

No noise.

**Example 4: α_bar_t = 0**

```math
x_t=\sqrt{0}x_0+\sqrt{1}\epsilon=\epsilon
```

Pure noise.

**PYQ/PYQ-style Questions**

1. Define `β_t`, `α_t`, and `α_bar_t`.
2. Derive direct sampling equation from repeated noising.
3. What happens when `α_bar_t=1`?
4. What happens when `α_bar_t=0`?

**Common Traps**

- `α_t=1-β_t`, but `α_bar_t` is product of all previous alphas.
- Direct formula samples `x_t` from `x0`, not from `x_(t-1)`.
- `β_t` is variance schedule, not standard deviation.
- Noise term coefficient is square root.

**Memory Trick:** `α_bar keeps signal; 1-α_bar gives noise`.

# SECTION 9 - DDPM REVERSE PROCESS

## 9.1 Why Reverse Must Be Learned

Forward noising is easy because we choose the Gaussian schedule. Reverse denoising is hard because from noisy `x_t`, many possible clean images could exist.

**Punjabi intuition:** Photo te noise pauna easy hai. Noise vichon original photo wapas banana intelligence mangda.

## 9.2 Reverse Distribution

True reverse:

```math
q(x_{t-1}|x_t)
```

Learned reverse:

```math
p_\theta(x_{t-1}|x_t)
=N(\mu_\theta(x_t,t),\Sigma_\theta(x_t,t))
```

**Additional Concept:** Exact posterior often conditions on `x0` as `q(x_{t-1}|x_t,x0)`, but requested prompt specifically mentions `q(x_(t-1)|x_t)`.

## 9.3 Noise Prediction

Common DDPM network prediction:

```math
\epsilon_\theta(x_t,t)
```

**Symbols:**

- `ε_theta` = neural network predicted noise
- `θ` = model parameters
- `x_t` = noisy input
- `t` = timestep
- output = estimated noise `ε_hat`

Training loss:

```math
L=E\left[||\epsilon-\epsilon_\theta(x_t,t)||^2\right]
```

## 9.4 x0 Prediction from Noise Prediction

From forward equation:

```math
x_t=\sqrt{\bar{\alpha}_t}x_0+\sqrt{1-\bar{\alpha}_t}\epsilon
```

Solve for `x0`:

```math
\hat{x}_0=
\frac{x_t-\sqrt{1-\bar{\alpha}_t}\epsilon_\theta(x_t,t)}
{\sqrt{\bar{\alpha}_t}}
```

**Additional Concept:** Some models predict `x0` directly or predict reverse mean directly.

## 9.5 Numerical Example

If `x_t=1.0`, `α_bar_t=0.64`, predicted `ε=1`:

```math
\hat{x}_0=\frac{1.0-\sqrt{0.36}(1)}{\sqrt{0.64}}
```

```math
\hat{x}_0=\frac{1.0-0.6}{0.8}=0.5
```

## 9.6 Timestep Conditioning

Same noisy image value can mean different things at different timesteps. Therefore U-Net receives both:

```math
(x_t,t)
```

At small `t`, image mostly clean. At large `t`, image mostly noise.

**PYQ/PYQ-style Questions**

1. Why is reverse process learned?
2. What does `ε_theta(x_t,t)` predict?
3. Write DDPM MSE noise prediction objective.
4. Why is timestep `t` given to the model?

**Common Traps**

- Reverse process is not simply subtracting random noise blindly.
- DDPM commonly predicts noise, not class label.
- `x0` prediction, noise prediction, and mean prediction are different targets.
- U-Net is conditioned on timestep.

**Memory Trick:** `DDPM training = add known noise, ask model to predict that noise`.

# SECTION 10 - U-NET

## 10.1 Definition

U-Net is an encoder-decoder neural network with skip connections. In diffusion, it usually predicts noise:

```math
\epsilon_\theta(x_t,t)
```

**Important:** U-Net is the neural network used inside diffusion; it is not the diffusion process itself.

**Punjabi intuition:** U-Net noisy image nu compress karke global meaning samajhda, then decode karke pixel-level noise prediction karda. Skip connections fine details bachaunde ne.

## 10.2 Architecture

```text
Input x_t + timestep t
→ Encoder / Downsampling
→ Bottleneck
→ Decoder / Upsampling
→ Noise prediction epsilon_hat
```

Skip connections:

```text
Encoder feature → concatenate with matching decoder feature
```

## 10.3 Components

| Component | Role |
|---|---|
| Encoder | captures features while reducing spatial size |
| Downsampling | reduces height/width, increases receptive field |
| Bottleneck | most compressed representation |
| Decoder | restores spatial resolution |
| Upsampling | increases height/width |
| Skip connections | preserve fine spatial details |
| Feature maps | intermediate tensors |
| Channels | number of feature dimensions |
| Timestep embeddings | inject noise-level information |

## 10.4 Tensor-Shape Numerical Examples

**Skip concatenation**

Encoder feature:

```text
32×32×128
```

Decoder feature:

```text
32×32×64
```

Concatenate channels:

```text
32×32×(128+64)=32×32×192
```

**Downsampling example**

Input:

```text
64×64×32
```

Downsample by factor 2:

```text
32×32×64
```

Often spatial size decreases, channels increase.

**Additional Concept: Convolution output size**

```math
Output=\left\lfloor\frac{N+2P-K}{S}\right\rfloor+1
```

where `N=input size`, `P=padding`, `K=kernel`, `S=stride`.

Example: `N=32`, `P=1`, `K=3`, `S=1`:

```math
Output=\frac{32+2-3}{1}+1=32
```

## 10.5 U-Net Role in Diffusion

```text
DDPM = diffusion mathematical framework + U-Net denoising network
```

The U-Net learns:

```math
(x_t,t)\rightarrow \hat{\epsilon}
```

# SECTION 11 - DDIM

## 11.1 Why DDPM Sampling Is Slow

DDPM may use many steps, often around `T=1000` in classic settings:

```text
x_T → x_(T-1) → ... → x_0
```

This is slow.

## 11.2 DDIM Definition

DDIM allows faster sampling by using fewer steps and can be deterministic.

**Punjabi intuition:** DDPM har stair te rukda. DDIM selected stairs skip karke jaldi neeche aa sakda.

## 11.3 eta Parameter

```math
\eta
```

Important case:

```math
\eta=0 \Rightarrow deterministic DDIM sampling
```

If `η>0`, sampling can include stochasticity.

**Additional Concept:** Full DDIM sampling formula depends on notation from source notes. Since attachments are unavailable, exact source-specific formula is not asserted here.

## 11.4 DDPM vs DDIM

| DDPM | DDIM |
|---|---|
| usually stochastic sampling | can be deterministic |
| many sampling steps | fewer sampling steps possible |
| slower | faster |
| Markovian reverse chain | can use non-Markovian trajectory |
| common training objective predicts noise | often reuses trained DDPM noise predictor |

**PYQ/PYQ-style Questions**

1. Why is DDPM sampling slow?
2. What does DDIM improve?
3. What happens when `η=0`?
4. Compare DDPM and DDIM in two points.

**Common Traps**

- DDIM is not a different U-Net architecture by default.
- `η=0` means deterministic sampling.
- Fewer steps can be faster but may affect quality depending on schedule.
- DDIM sampling and DDPM training objective should not be mixed blindly.

**Memory Trick:** `DDIM = DDPM-style denoising, fewer steps, eta controls randomness`.

# ONE-PAGE FORMULA SHEET

## f-Divergence and Variational Form

```math
D_f(P||Q)=E_Q[f(P(x)/Q(x))]
```

```math
f^*(u)=\sup_t\{ut-f(t)\}
```

```math
D_f(P||Q)=\sup_T\{E_P[T]-E_Q[f^*(T)]\}
```

```math
T^*(x)=f'(P(x)/Q(x))
```

## GAN

```math
\min_G\max_D E_{x\sim P_{data}}[\log D(x)]
+E_{z\sim p(z)}[\log(1-D(G(z)))]
```

```math
D^*(x)=\frac{P_{data}(x)}{P_{data}(x)+P_g(x)}
```

```math
\frac{P_{data}}{P_g}=\frac{D^*}{1-D^*}
```

## WGAN

```math
W_1(P,Q)=\sup_{\|D\|_L\le1}(E_P[D]-E_Q[D])
```

```math
GP=\lambda(\|\nabla D(\hat{x})\|_2-1)^2
```

## VAE

```math
q_\phi(z|x)=N(\mu(x),\sigma^2(x))
```

```math
z=\mu+\sigma\epsilon,\quad \epsilon\sim N(0,I)
```

```math
L_{VAE}=L_{rec}+D_{KL}(q_\phi(z|x)||p(z))
```

```math
D_{KL}=\frac12\sum_i(\mu_i^2+\sigma_i^2-1-\log\sigma_i^2)
```

## beta-VAE

```math
L_\beta=L_{rec}+\beta KL
```

## VQ-VAE

```math
z_q=e_k,\quad k=\arg\min_j ||z_e-e_j||_2
```

## DDPM Forward

```math
\alpha_t=1-\beta_t
```

```math
\bar{\alpha}_t=\prod_{s=1}^{t}\alpha_s
```

```math
q(x_t|x_{t-1})=N(\sqrt{1-\beta_t}x_{t-1},\beta_t I)
```

```math
x_t=\sqrt{1-\beta_t}x_{t-1}+\sqrt{\beta_t}\epsilon
```

```math
q(x_t|x_0)=N(\sqrt{\bar{\alpha}_t}x_0,(1-\bar{\alpha}_t)I)
```

```math
x_t=\sqrt{\bar{\alpha}_t}x_0+\sqrt{1-\bar{\alpha}_t}\epsilon
```

```math
\epsilon_\theta(x_t,t)
```

```math
L=E[||\epsilon-\epsilon_\theta(x_t,t)||^2]
```

```math
\hat{x}_0=
```

# MODEL COMPARISON TABLE

| Model | Main Idea | Main Math | Strength | Weakness / Trap |
|---|---|---|---|---|
| f-divergence | compare distributions | `E_Q[f(P/Q)]` | unified divergence family | not Wasserstein |
| GAN | adversarial generation | minimax objective | sharp samples | unstable, mode collapse |
| WGAN | Earth Mover distance | `sup E_P[D]-E_Q[D]` | better gradients | needs 1-Lipschitz critic |
| VAE | probabilistic latent model | reconstruction + KL | explicit encoder, smooth latent | blurry samples |
| beta-VAE | stronger KL control | `L_rec + βKL` | disentanglement pressure | high β hurts reconstruction |
| VQ-VAE | discrete latent codebook | nearest code vector | token-like latent | quantization needs estimator |
| DDPM | learned denoising | noise prediction MSE | high-quality generation | slow sampling |
| U-Net | denoising network | `(x_t,t)→ε_hat` | preserves image details | not diffusion itself |
| DDIM | faster diffusion sampling | `η=0` deterministic | fewer steps | quality/speed tradeoff |

# CONCEPT MAP

```text
Generative AI Goal
  → make model distribution P_g close to real distribution P_data

Distribution Comparison
  → f-divergence
    → KL / JS / TV / Pearson chi-square
    → variational representation
    → critic estimates divergence

GAN
  → generator creates fake samples
  → discriminator detects real/fake
  → optimal D gives density ratio
  → problems: vanishing gradient, instability, mode collapse

WGAN
  → replaces JS-style behavior with Wasserstein distance
  → discriminator becomes critic
  → needs 1-Lipschitz
  → weight clipping or gradient penalty

VAE Family
  → encoder gives μ, σ
  → reparameterization z=μ+σε
  → loss = reconstruction + KL
  → beta-VAE changes KL strength
  → VQ-VAE changes continuous z into discrete codebook z_q

Diffusion
  → forward process adds Gaussian noise
  → DDPM forward uses β_t, α_t, α_bar_t
  → reverse process learns denoising
  → U-Net predicts ε from x_t and t
  → DDIM speeds up sampling with fewer/deterministic steps
```

## High-Probability Exam Traps

1. Wasserstein distance is not an f-divergence.
2. GAN discriminator gives probability; WGAN critic gives score.
3. beta-VAE `β` is not diffusion `β_t`.
4. `α_t=1-β_t`; `α_bar_t` is product of alphas.
5. U-Net is the network inside diffusion, not the full diffusion process.
6. DDPM forward process is fixed; reverse process is learned.
7. DDPM commonly predicts noise `ε`, not directly the final image in the basic objective.
8. DDIM with `η=0` is deterministic.
